# Marketing screenshots

The PNGs in this directory are the screenshots used in the project README and
docs. They are captured from a throwaway SickRock stack seeded with fictional
data ("Fernbrook Gardens", a made-up landscaping business), so every run
produces the same images apart from timestamps.

## Requirements

- `podman` (or Docker: `make CONTAINER=docker`)
- `repo-helper`, Chrome/Chromium and a matching `chromedriver`
- Go, Node.js, `jq` and `curl`

## Regenerate

```bash
make                  # from this directory, or `make screenshots` from the repo root
```

This builds the service and frontend, starts a temporary MariaDB container on
`127.0.0.1:13306` and SickRock on `127.0.0.1:18480`, seeds data through the
Connect API (`seed.sh`), captures every section in `screenshots.ini`,
regenerates `screenshot-manifest.yaml`, copies the images into the docs and
tears everything down, even if a step fails.

To browse the seeded stack yourself, run `make up seed`, open
<http://127.0.0.1:18480/> and sign in as `admin` / `fernbrook-demo`. Run
`make down` when you're done.

## Files

- `screenshots.ini`: one section per image, with the `title` and `description`
  used for the manifest and README captions.
- `screenshot-manifest.yaml`: generated by `make manifest`; do not edit.
- `seed/`: the fictional tables, rows, views and sidebar apps. Dates written as
  `@day+3 09:30` are relative to the day the seed runs.
- `service.yaml`, `SickRock.env`: config for the throwaway service. The env
  file is copied into `tmp/service/`, which SickRock searches before
  `~/.config/SickRock/`, so a developer's own database settings are never used.
- `scripts/`: Selenium setup scripts (sign in, theme, sidebar, calendar view).
